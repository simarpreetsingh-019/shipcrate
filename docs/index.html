shipcrate

Release and update tooling for your products, in one command. Quality gate, GitHub releases with checksums and provenance, Homebrew, installers and update checks for macOS, Linux and Windows. Works by hand and with AI coding agents.

sh scripts/release.sh 0.1.0 --dry-run         # build + notes, publishes nothing

What you get

One quality gate

Build, tests, secret scan, lint and dependency audit for Rust, Swift, Python and Node. It runs on every commit, push, CI run and release.

One-command releases

Guardrails, then build, SHA-256, latest.json, GitHub release with "What's new", Homebrew tap bump and webhook.

Every platform

Native CI builds for macOS, Linux and Windows on x64 and arm64. Per-platform Homebrew checksums, plus install.sh and install.ps1.

Update checks

An in-app Update button for Swift apps. For Rust, Python and Node CLIs: a once-a-day notice and upgrade with rollback.

Your notifications

Hooks for your own notification UI, a signed webhook to your push server, or a manifest your servers can poll.

Agent-ready

Skills for Claude Code and Codex, plus AGENTS.md and a Cursor rule. Agents ask before they push or publish.

Security built in

GuardWhat it does
Release guardrailsReleases only from the default branch, with green CI for that commit, a CHANGELOG entry, a newer version and a clean tree.
Strict release gateNothing can be skipped: tests, audits, secret scan and workflow lint must all pass.
Checksums + provenanceSHA-256 for every file and actions/attest-build-provenance. Tampered downloads are refused.
Shipped testsEvery project gets tests that prove a tampered release can't install and that upgrade and rollback work.
No telemetryThe update check is one anonymous GET, at most daily, never in CI, and you can turn it off.
