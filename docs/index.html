Updates your users will notice.

In the app, an Update button. In the terminal, one quiet line a day at most, and a loud one for security fixes.

↓ Update
msh 0.3.0 is available · msh upgrade
⚠ SECURITY UPDATE: msh 0.3.1 fixes a security issue

Works with your notifications.

Show updates in your own UI, get a signed webhook on your push server, or have it poll one manifest.

release→latest.json→your server→APNs · FCM · email

Rollback,
built in.

Upgrades swap atomically and keep the previous version. One command undoes it.

Beta first. Then everyone.

Ship 1.4.0-beta.1 to opted-in users, then release to 10%, 50%, 100%. A bad build? Yank it, and every copy is moved back to the last good version.

beta→10%→50%→100%·yank ↩

Talk to every user.

One command sends a message to every installed copy. No release needed.
